# Tanned Co.

A modern website for **Tanned Co.** — a premium tanning brand. Built with [Next.js](https://nextjs.org) and deployed on [Vercel](https://vercel.com).

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Deployment:** Vercel

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Project Structure

```
src/
├── app/
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
└── components/
```

## Deployment

This site is deployed on Vercel. Every push to `main` triggers an automatic deployment.
